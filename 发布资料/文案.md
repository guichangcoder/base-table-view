### 详情介绍 *（上限 3000 字）

```
表格前端（Base Table View）是面向飞书多维表格「多字段大宽表」的前端展示插件。它把一条记录里的几十个字段，按业务含义重新组织成清晰的分组卡片，让不熟悉数据表的同事也能一眼看懂、顺手填写。

【解决什么问题】
多维表格擅长存数据，但当一张表有 30 个以上字段、又包含多个关联字段时，默认的记录详情往往是长长一串字段平铺下来，业务同事找不到重点，填错率也高。表格前端在不改动数据表结构的前提下，为同一张表提供一套「业务视图」。

【核心能力】

1. 字段分组，用颜色区分
在插件内自由建立分组（如基本信息、金额信息、关联信息），字段可跨组调整归属；每个分组可单独设定配色，纵向阅读、无需横向滚动。

2. 重点字段强调
对需要关注的字段开启强调：加粗、字体颜色、背景高亮。金额、截止日期这类关键信息不再被淹没在字段堆里。

3. 必填校验与前端写回
可为任意字段设置「必填」，保存前统一校验并定位到缺失项；填写内容直接写回多维表格原表，不产生第二份数据。

4. 只读字段
同步字段、公式字段或无权限字段可设为「只读」，前端置灰仅展示，避免误改。

5. 关联字段纵向展开
关联字段可按表格形式纵向展开，并可指定展示关联表中的哪几列、每行展示多少条，不用在标签页之间来回切换。

6. 筛选与关键词搜索
配置阶段可指定可筛选字段与筛选方式；使用阶段支持多条件组合筛选 + 关键词搜索 + 分页加载，万级记录也能顺畅使用。

7. 按钮字段原样呈现
数据表中已配置自动化流程的「按钮」字段，在插件内以相同的标题与颜色呈现。点击后打开该字段的原生记录详情，在原位点击即执行对应工作流，效果与在数据表内点击一致（实际执行权限遵循飞书原生的字段与自动化权限）。

【怎么用】
第一步：在飞书多维表格「应用模式」中添加本插件，绑定目标数据表。
第二步：进入配置态，建立分组、勾选字段、设置显示 / 必填 / 只读、配置筛选条件与分组配色，保存。
第三步：普通同事直接打开插件，选择记录即可阅读与填写。

【适合谁】
合同、订单、客户、项目、设备台账等字段多、关联多的业务台账；希望把多维表格「藏起来」，只给业务同事一个干净填写界面的团队。

【说明】
本插件为多维表格应用模式（App-Mode）插件，需在应用模式的页面中通过「添加插件」安装；配置结果保存在当前多维表格内，不涉及任何外部服务器。
```

### 帮助文档（文本框）

```
安装：进入多维表格「应用模式」→ 打开目标页面 → 添加插件 → 选择「表格前端」。

配置：切换到配置态，左侧新建分组并命名；在字段列表中勾选要展示的字段，可设置「显示 / 必填 / 只读」，点击类型标签可切换按钮字段的特殊渲染；右侧设置分组配色与强调方式；「筛选与搜索」中可指定可筛选字段；完成后保存。

使用：普通成员打开插件即进入使用态，左侧选择记录，右侧按分组阅读与填写；顶部支持关键词搜索与多条件筛选。

常见问题：
1）字段没有出现 —— 检查该字段是否已在配置态勾选，且所属分组未被清空。
2）按钮点不动 —— 插件无法直接调用自动化流程，点击会打开该字段的原生记录详情，请在原生详情中点击按钮执行。
3）关联字段内容为空 —— 请确认关联字段本身在当前记录中已有值，且当前账号对关联表有查看权限。
```
